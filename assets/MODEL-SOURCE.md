# Larva model reference

The body silhouette is based on the upper-left *Drosophila melanogaster* panel in the user-supplied reference collage. The remaining five panels depict other *Drosophila* species and were used only as general references for translucent cuticle, segment folds, mouth hooks, and posterior spiracles.

The repository does not redistribute the reference photograph because its publication and licence metadata were not provided. `drosophila-melanogaster-larva.glb` is an original low-poly-to-smooth reconstruction generated by `tools/export-larva-glb.mjs`.
